## How to Take Screenshots

1. Open the live app: https://smart-knowledge-gap-system-qqbms.faable.link/
2. Follow the flow: register → assessment → results → dashboard → learning → practice
3. Take screenshots at each step
4. Save them here with the exact filenames listed above

## Notes

- All screenshots should be from a real session for consistency.
- PNG or JPG format both work.
- Recommended resolution: at least 750px wide.
