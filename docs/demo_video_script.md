## Recording Tips

1. **Do a dry run first** — practice the flow without recording.
2. **Speak slowly and clearly** — if voiceover, else add subtitles.
3. **Move the mouse slowly** — let viewers follow the action.
4. **Pause briefly between scenes** — makes editing easier.
5. **Use full screen** — no browser tabs visible.
6. **Watch out for notifications** — turn on Do Not Disturb.
